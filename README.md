# TypeDash

Typing speed test with live WPM and accuracy, personal best record, and curated practice texts.

Single-file web app (pure HTML + CSS + JavaScript). No server, no build, no dependencies.

## Run
Open `index.html` in any modern browser. Everything (drafts, stats, records) is stored in localStorage.

## Rebrand
Edit the `CONFIG` block at the top of the `<script>` and the CSS variables at the top of `<style>`.

## Deploy free
GitHub Pages: push to a repo, Settings > Pages > main / root.
Netlify: drag this folder into app.netlify.com.
Vercel: `vercel` in this folder, or import the repo at vercel.com/new.
